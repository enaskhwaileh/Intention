# Annotation guidelines status

Annotation tooling and judgments do not yet exist. The future annotation unit
is a user request, intended action, and single candidate table.

Annotators must judge independently:

1. topical relevance;
2. action suitability from 0 (unsuitable) to 3 (strongly suitable); and
3. whether the evidence needed for that judgment is observable.

Annotators must not see the system's final score as ground truth. Guidance must
record ambiguity, missing evidence, contradictions, unsupported actions, and
the non-causal meaning of `explain`.
