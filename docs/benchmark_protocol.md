# Benchmark protocol status

No external benchmark is downloaded, adapted, or evaluated in Phases 0–2.

The planned protocol must separate topical relevance, intended-action
suitability, and evidence observability. Action suitability uses a documented
graded label rather than replaying the system score. A meaningful subset must
receive at least two independent annotations, report agreement, and split
development from test data by topic.

Each future adapter must record source, venue, license, version, checksum,
download steps, preprocessing, exclusions, and redistribution constraints.
Full raw corpora must remain outside Git.
