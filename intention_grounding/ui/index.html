Datasets & provenance

  • Now: four-row synthetic table and manually authored replay fixtures.
  • Main benchmark proposed: UCI/OpenML tables with independent Compare/Predict usefulness judgments.
  • External candidate: FollowTable, subject to protocol, licensing and label-compatibility checks.
  • Regression only: original semantic-matching/TABERTA data after artifact and overlap review.

Baselines & evaluation

BM25, our published semantic-matching method, TABERTA, Qwen embeddings, Qwen reranker, and direct LLM usefulness assessment. All require integration; exact published variants remain gated.

Primary: usefulness nDCG@10. Also Success@1, Recall@10, verdict macro-F1, false-support rate, coverage, latency and cost.

Compare identical-candidate reranking first, then end-to-end retrieval with candidate recall. Gold stays outside runtime ranking. Unresolved is never silently negative.

How we will choose the best fit

  1. Freeze independently annotated development/validation/test sets, separated by topic and source family.
  2. Screen model/schema compatibility and measure valid outputs, semantic bindings and evidence citations.
  3. Compare usefulness quality, false support, abstention, p50/p95 latency, tokens, cost and memory under matched budgets.
  4. Select on validation results and resource limits; freeze before testing. Report tradeoffs and failures, not a universal winner.
